# 我的语言学习软件

纯前端多语言学习工具，支持英语、日语、生造语等词库切换。

## 功能
- 单词卡片（单词、音标、发音、例句、例句发音）
- 自评标记（熟悉/模糊/陌生，总览颜色同步）
- 手写画板（保存/清除/恢复）
- 语法、字母表、短语、测验
- 多语言切换
- eSpeak NG WASM 按 IPA 发音

## 运行
直接双击 `index.html` 即可（无需服务器）。
