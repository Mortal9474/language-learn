  多语言学习工具
  Language Learning App
═══════════════════════════════════════════════

一个纯前端的语言学习 Web 应用，支持多语言词库切换、
IPA 音标发音、手写画板、多主题、学习统计等功能。


───────────────────────────────────────────────
  一、功能特性
───────────────────────────────────────────────

【学习模块】
  · 单词卡片 — 单词、音标、发音、搭配、自评标记
  · 搭配     — 词组搭配 + 中文释义 + 发音
  · 语法     — 20 条核心语法，含规则、结构、例句、练习
  · 字母表   — 26 字母 + 音标 + 例词 + 描红画板
  · 短语     — 常用语，可点开查看详情
  · 测验     — 选择题，答错进错题本
  · 错题本   — 连续答对 3 次自动移除

【分类与标记】
  · 自评标记 — 熟悉 / 模糊 / 陌生
  · 单词分类 — 全部 / 熟悉 / 模糊 / 陌生 / 未学习
  · 卡片颜色 — 状态色随主题变化

【收藏与统计】
  · 收藏     — 单词、搭配、语法三类独立收藏
  · 统计     — 学习进度、测验正确率、连续天数、7 天图表

【发音】
  · eSpeak NG WASM 按 IPA 音标合成
  · 失败自动回退浏览器 TTS
  · 支持多语言语音切换

【手写】
  · 鼠标 + 触摸书写
  · 橡皮、撤销、清空
  · 保存到 localStorage，下次打开自动恢复
  · 字母表描红练习

【批注】
  · 每个板块底部可打字批注
  · 支持手写批注
  · 持久化保存

【主题】
  · 5 个预设主题：简洁、竹韵、古风、月下、霓虹
  · 自定义主题：调色 + 自动对比画笔色
  · 主题持久化
  · 所有颜色跟随主题变化

【多语言】
  · 语言切换按钮
  · 数据与逻辑分离，加新语言只改数据
  · 内置：奥曼语、英语（可扩展）

───────────────────────────────────────────────
  三、如何运行
───────────────────────────────────────────────

方式一：直接打开（推荐）
  双击 index.html 即可。

方式二：本地服务器
  python -m http.server 8000
  浏览器打开 http://localhost:8000


───────────────────────────────────────────────
  四、如何添加新语言
───────────────────────────────────────────────

1. 在 data/ 下新建文件夹，如 data/fr/
2. 放入四个文件（文件名不能改）：
     words.js      单词
     grammar.js    语法
     alphabet.js   字母表
     phrases.js    短语
3. 在 data/languages.js 中注册一项：
     {
       code: "fr",
       name: "法语",
       espeakVoice: "fr",
       words:    "data/fr/words.js",
       grammar:  "data/fr/grammar.js",
       alphabet: "data/fr/alphabet.js",
       phrases:  "data/fr/phrases.js"
     }
4. 刷新页面即可。

每个数据文件用 window.XXX = [...] 挂载，例如：
  window.WORDS    = [...]
  window.GRAMMAR  = [...]
  window.ALPHABET = [...]
  window.PHRASES  = [...]


───────────────────────────────────────────────
  五、数据格式
───────────────────────────────────────────────

【words.js】
  window.WORDS = [
    {
      id: "en001",
      word: "ability",
      display: "ability",
      phonetic: "/ə'bɪləti/",
      ipa: "@'bIl@ti",
      meaning: "能力，才能",
      pos: "n.",
      level: "CET4",
      examples: [
        { con: "innovation ability", zh: "创新能力", ipa: "" }
      ]
    }
  ]

【grammar.js】
  window.GRAMMAR = [
    {
      id: "en_g001",
      title: "一般现在时",
      level: "A1",
      explanation: "表示习惯性动作。",
      structure: "主语 + 动词原形",
      examples: [
        { con: "She works.", zh: "她工作。", ipa: "" }
      ],
      exercises: [
        { type: "fill", question: "He ___ (go).", answer: "goes" }
      ]
    }
  ]

【alphabet.js】
  window.ALPHABET = [
    {
      char: "A",
      display: "A a",
      name: "A",
      phonetic: "/eɪ/",
      ipa: "eI",
      example: { word: "apple", meaning: "苹果", ipa: "&p@l" }
    }
  ]

【phrases.js】
  window.PHRASES = [
    {
      id: "en_p001",
      text: "How are you?",
      display: "How are you?",
      meaning: "你好吗？",
      phonetic: "/haʊ ɑːr juː/",
      ipa: "",
      scene: "greeting",
      examples: []
    }
  ]


───────────────────────────────────────────────
  六、eSpeak IPA 写法对照
───────────────────────────────────────────────

  IPA     eSpeak     说明
  ─────────────────────────────
  θ       T          清齿擦音
  ʃ       S          清龈后擦音
  ʒ       Z          浊龈后擦音
  ŋ       N          软腭鼻音
  æ       &          次开前不圆唇元音
  ʌ       V          次开后不圆唇元音
  ə       @          中央元音
  ɜː      3          长中央元音
  ɔː      O          长开后圆唇元音
  ɪ       I          次闭次前不圆唇元音
  ʊ       U          次闭次后圆唇元音
  iː      i          长闭前不圆唇元音


───────────────────────────────────────────────
  七、技术栈
───────────────────────────────────────────────

  · 纯前端：HTML + CSS + JavaScript
  · 无框架依赖
  · 数据与逻辑分离
  · 存储：localStorage
  · 发音：eSpeak NG WASM（CDN 加载）
  · 手写：HTML5 Canvas
  · 数据加载：<script> 标签 + window 全局变量
    （不用 fetch，支持 file:// 双击运行）
